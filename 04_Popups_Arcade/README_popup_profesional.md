# Popups Arcade

## Preparación

Antes de pegar las expresiones, reemplazar:

- `<RELATIONSHIP_NAME_POINT>` o `<RELATIONSHIP_NAME_LINE>` por el nombre REST real.
- `<URL_TABLA_PADRE_SURVEY>` por la URL REST completa de la tabla padre, sin barra final.
- Mantener `var token = "<TOKEN_GESTIONADO_AUTOMATICAMENTE>";` para que el actualizador Regex pueda renovarlo.

## Instalación

1. Abrir el Web Map de revisión.
2. Configurar el popup de la capa hija correspondiente.
3. Agregar contenido de tipo expresión Arcade.
4. Pegar el archivo completo.
5. Guardar el Web Map y registrar su Item ID en la configuración.
6. Ejecutar el notebook de tokens en simulación y confirmar el número de coincidencias.
7. Probar atributos, fotos y archivos con un registro relacionado.

No distribuir tokens reales dentro de estos archivos.
